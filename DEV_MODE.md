# Режим разработки

Production XYPDF фиксируются на релизном Git tag. Для проверки изменений до выпуска разрешено временно создать локальную копию импортируемого JSON и заменить `#v1.2.0` на `#main`.

Такой dev-файл не должен импортироваться в production и не должен заменять основной XYPDF в репозитории.
